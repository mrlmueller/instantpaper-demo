# Shared Label Rubric

Use this rubric for all benchmark tracks.

## Section relevance labels

- `0`: irrelevant
- `1`: weak / tangential
- `2`: useful
- `3`: highly useful / central for writing the chapter

## Document-level outcome

For each document, annotate:
- `has_useful_information`: `true` or `false`

Rule of thumb:
- `true` if at least one section deserves label `2` or `3`
- `false` if no section is meaningfully useful for the target chapter

## Notes to record

For every labeled section, capture:
- why it is relevant
- which subpoint(s) it supports
- whether relevance is obvious from the heading or only from the body

This metadata is important later for error analysis.
