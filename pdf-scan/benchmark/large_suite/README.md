# Large Suite

Do not fully populate this yet.

## Build now, populate later

This suite should exist structurally from the start so the pipeline can target a stable benchmark format, but the actual chapter and document collection should wait until:

- canonical section construction is implemented
- retrieval output format is stable
- reranking output format is stable

## Planned target shape

- many chapter inputs
- dozens of PDFs
- positive, partial, and negative documents
- formal regression usage

## When to start filling it

Start populating this suite after:

1. Phase B and C are working reliably on the small suite
2. candidate retrieval is no longer changing every day
3. section ids / titles / references are stable enough to annotate once
