# Annotation Plan

Do not finalize section judgments until the new pipeline has stable Phase B and Phase C outputs.

## Annotation rule

Do not import any fit assumptions from:
- file length
- title wording
- document profile names

The annotation must be driven only by:
- actual section content
- actual usefulness for the chapter

## Annotation workflow

For each document:

1. inspect the canonical sections produced by the pipeline
2. mark `has_useful_information` only after reading the relevant section candidates
3. assign section labels on the shared `0..3` rubric
4. note which subpoints are actually supported

## Why this file exists

This keeps the benchmark honest:
- document selection can be pragmatic
- gold labels remain evidence-based
